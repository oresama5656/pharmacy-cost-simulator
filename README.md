# 調剤薬局 粗利単価＆資材コスト気づきシミュレーター

調剤薬局の現場スタッフ・店長向け「コスト意識向上・粗利シミュレーション」Webアプリケーション。

技術料単価から、日々の調剤・投薬業務で消費される資材費（薬袋、薬情カラー/白黒印刷、おくすり手帳シール、ジップロック、一包化分包紙など）を差し引き、「1処方あたりの本当の粗利単価」と「年間処方箋枚数に応じた年間粗利総額・資材コスト総額」を直感的にシミュレーションできます。

---

## 🎯 開発の目的（Core Value）

- **本部による管理・監視ツールではなく、「現場の自発的なコスト意識の向上」** を目的としています。
- 「うちの店舗、消耗品だけで年間こんなに費用がかかっていたのか！」という**驚き（気づき）**。
- 「この資材や運用を1つ見直すだけで、年間こんなに利益が増えるなら頑張ろう！」という**改善へのモチベーション（アハ体験）**。

---

## ✨ 主な機能

1. **リアルタイムな粗利単価・年間粗利試算**
   - 1処方あたりの技術料単価 － 使用資材費 ＝ 粗利単価（純技術料）
   - 年間処方箋枚数（月1,000枚〜4,000枚等のスライダー・ワンタッチ設定）と連動した年間粗利シミュレーション。
2. **現場のコスト気づき指標（処方箋枚数換算）**
   - 「年間〇〇万円が資材代として消えています（＝処方箋 約〇〇枚分の技術料に相当）」と表示し、コストの重みを実感できます。
3. **処方パターンの多様性（複数プロファイル＆比率ミックス）**
   - 「通常外来処方」「一包化・多剤処方」「小児・外用・混合処方」の3パターンを搭載。
   - 処方割合スライダーによる加重平均試算、または単一パターンのみでのシンプル試算に対応。
4. **直感的な資材チェックリスト＆単価調整**
   - カラー薬情、モノクロ薬情、領収書、手帳シール、手帳冊子、各種薬袋、チャック袋、保冷バッグ、分包紙、軟膏容器、水剤ボトル等。
   - チェックボックス（✓）のON/OFF、使用数量（＋/－）、単価変更が即時連動。
   - 店舗独自のオリジナル資材・消耗品の追加・削除も可能。
5. **「コレ変えたらいくら浮く？」改善シミュレーター（やる気スイッチ）**
   - 「カラー薬情をモノクロへ変更」「ジップロック配布の半減」「一包化のロス削減」などをワンクリックで切り替え。
   - 「現状として基準セット」機能により、見直し前後の年間利益差額（年間＋〇〇万円）をハイライト。
6. **ゼロビルド＆オフライン動作**
   - Node.jsやビルド環境不要。`index.html` をブラウザで開くだけで即座に動作。設定はブラウザのLocalStorageに自動保存されます。

---

## 🚀 使い方

1. 本リポジトリをダウンロード（またはクローン）します。
2. `index.html` をダブルクリックして任意のブラウザ（Chrome, Edge, Safari等）で開きます。
3. 店舗の年間処方箋枚数や、普段使っている資材にチェックを入れてシミュレーションを開始してください。
